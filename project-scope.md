# AI-Powered Ticket Management System

## Problem

We receive hundreds of support emails daily. Our agents manually read, classify, and respond to each ticket — which is slow and leads to impersonal, canned responses.

## Solution

Build a ticket management system that uses AI to automatically classify, respond to, and route support tickets — delivering faster, more personalized responses to students while freeing up agents for complex issues.

## Features

- Receive support emails and create tickets
- Public contact form that creates tickets without an email (senders are answered at the address they give)
- Auto-resolve tickets on arrival using a knowledge base, emailing the answer and leaving them off the ticket list
- Email agents' replies to the ticket's sender
- Ticket list with filtering and sorting
- Ticket detail view
- AI-powered ticket classification 
- AI summaries
- AI-suggested replies
- User management (admin only)
- Dashboard to view and manage all tickets

## Ticket Statuses

A ticket has exactly one status at a time:

- Open
- Resolved
- Closed

## Ticket Categories

A ticket belongs to exactly one category:

- General Question
- Technical Question
- Refund Request

## User Roles

- **Admin**: The system is deployed with one admin account already set up. The admin creates and manages additional agents.
- **Agent**: Created by the admin. Can view and manage tickets.
